# itd-spam

Скрипты для автоматической отправки сообщений в ИТД (итд.com).

---

## Содержимое

- **`spam.js`** — базовый скрипт, отправляет сообщение с ссылкой на репозиторий.
- **`spamwithrandomletters.js`** — улучшенная версия, добавляет к сообщению случайные символы для обхода простых фильтров.

---

## Как это работает (кратко)

Оба скрипта:
- Очищают консоль и выводят статус.
- Получают свежий токен через `POST /api/v1/auth/refresh` (на домене итд.com).
- В бесконечном цикле отправляют по 3 сообщения с паузой 1 мс между ними.
- Затем делают длинную паузу (60 или 61 секунду).
- При ошибках `429` (слишком много запросов) или `401` (неавторизован) цикл прерывается или пытается обновить токен.

---

## Как использовать (пошагово)

### Шаг 1. Авторизуйтесь на сайте
Откройте **https://итд.com** (или тот поддомен, который использует ваш сервис) и **войдите в свой аккаунт**. Скрипт использует вашу сессию, поэтому без авторизации он не сможет отправлять сообщения.

> **Примечание:** В адресной строке браузера домен может отображаться как `xn--80aeq.xn--...` (Punycode), но вы просто вводите в поиске «итд.com» — браузер сам преобразует.

### Шаг 2. Откройте консоль разработчика
- В браузере нажмите **F12** (или `Ctrl+Shift+I` / `Cmd+Option+I` на Mac).
- Перейдите на вкладку **Console** (Консоль).

### Шаг 3. Выберите скрипт и скопируйте его код
Перейдите в репозиторий и откройте нужный файл:
- [`spam.js`](./spam.js) — если хотите отправлять простое сообщение.
- [`spamwithrandomletters.js`](./spamwithrandomletters.js) — если хотите обфусцировать сообщение.

Нажмите кнопку **Raw** (или скопируйте весь код вручную).
