# itd-spam

Скрипты для автоматической отправки сообщений в ИТД.

## Содержимое

- **`spam.js`** — базовый скрипт, отправляющий сообщение с ссылкой на репозиторий.
- **`spamwithrandomletters.js`** — улучшенная версия, которая добавляет к сообщению случайные буквы и цифры для обхода простых фильтров.

## Как это работает

Оба скрипта:

1. Очищают консоль и выводят стартовое сообщение.
2. Получают токен авторизации через `POST /api/v1/auth/refresh`.
3. В бесконечном цикле отправляют по 3 сообщения подряд с паузой в 1 мс между ними.
4. После каждой тройки делают паузу:
   - `spam.js` — 60 секунд.
   - `spamwithrandomletters.js` — 61 секунду.
5. При получении кода `429` (Too Many Requests) или `401` (Unauthorized) цикл прерывается или токен обновляется.
